One endpoint per pipeline step

Each endpoint takes something a studio already has and returns files its tools open directly: a .blend, an Unreal project, GLB / USD, frames. The routes below are the proposed public names; the grey line under each one is where it runs today.

Interoperable

Outputs are native project files plus plain JSON manifests (scene.json, dials.json, shots.json), never just a video. Blender and Unreal open them as is.

Controllable

Every scene ships as a rig. Ten named dials (density, tidiness, wear, wetness, time of day, weather, atmosphere, power, warmth, look) are settings the builder must obey, and stay editable after the build.

Repeatable

Identical requests return the stored result (fresh rebuilds). Conversion and render steps are plain code, so the same input gives the same output. Agent steps stream every event and must pass an independent critic.

AnyShot and AnyKit are open source at github.com/apekshik/anyshot and /anykit; AnyScene at github.com/apekshik/anyscene.

Swappable stages: each endpoint is one step, so a generative model can replace a step when it is good enough. AnyShot renders with Cycles today and is designed to take an H3 Max render mode once drift is solved.
